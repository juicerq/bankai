# One owner for the shell list and the selection

The Continuity store owns the Shell list and one global selected session; the renderer holds no second copy and no command channel, and each mutation writes its projected result into the query cache so a gesture still repaints in its own commit. Ownership was split before — every mounted workspace kept its own tabs and its own selection so that opening one would not wait for a disk write — but two owners needed a per-project selection mirror, a registry of mounted workspaces, and a queue for commands aimed at a workspace that had not mounted yet, and the seam invented a Shell whenever a workspace mounted empty, which autostarted an agent on every restart. Optimistic writing buys back the latency the split existed to avoid, and the per-workspace `activeShellId` that split persisted answered a question no surface has asked since the session list replaced the tab strip.
