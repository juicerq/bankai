# The session list replaces the tab strip

Shells are reached through one sidebar list spanning every project, not through a per-workspace tab strip; `project-workspace-shell-tabs.tsx` and `Continuity.moveShell` were deleted with it, and creating, archiving and closing moved onto the sidebar — the header `+`, the row's hover box and cross, and the row context menu. A tab strip scopes to the active workspace, so reaching a shell in another project meant switching projects first, and it made a shell's position something the user maintained by dragging; a flat list ordered by creation reaches every session at equal cost and has no order to maintain. `Ctrl+X T` and `Ctrl+X X` moved out of the per-workspace shortcut hook into `useBankaiShortcuts` as a consequence, since there is no longer an active workspace for them to require.
